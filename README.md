# Backend-приложение аутентификации и авторизации пользователей написанное на FastAPI

Пользователи заполняют форму и регистрируются. Данные передаются и сохраняются в БД (кроме пароля, его значение хэшируется и в БД сохраняется хэш). Если при заполнении поле is_admin устанавливается в true (по умолчанию стоит в false), то пользователь является админом и ему доступны все действия над другими пользователями, в том числе их удаление. Удаление является мягким (все пользователи остаются в БД, меняется только флаг is_active пользователя внутри БД). Пользователи после регистрации могут менять свои данные (только если они были удалены администраторами).

При попытке пользователей совершать какие-либо действия, нарушающие логику программы (регистрировать email, который уже есть в БД, попытка удаленных пользователей совершать какие-либо действия и т.д), вызываются соответствующие исключения и выводятся информационные сообщения.


Для отладки приложения дополнительно написаны тесты на pytest. 

Деплой проекта для ознакомления доступен по адресу https://booking-fastapi-project.ru/
